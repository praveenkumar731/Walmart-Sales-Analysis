# Walmart Sales Analysis 📊

## 📌 Project Overview

This project performs an exploratory data analysis (EDA) of Walmart weekly sales data using Python and Jupyter Notebook.

The goal is to analyze store performance, sales trends, holiday impact, and the relationship between sales and other factors such as fuel price, temperature, CPI, and unemployment.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📂 Dataset

The dataset contains Walmart weekly sales information with the following columns:

- `Store` — Store number
- `Date` — Sales date
- `Weekly_Sales` — Weekly sales amount
- `Holiday_Flag` — Holiday indicator
- `Temperature` — Temperature
- `Fuel_Price` — Fuel price
- `CPI` — Consumer Price Index
- `Unemployment` — Unemployment rate

## 🔍 Data Analysis Performed

### Data Cleaning

- Checked missing values
- Checked duplicate records
- Converted `Date` from object to datetime
- Created month and year information for time-based analysis

### Exploratory Data Analysis

The project analyzes:

- Total weekly sales
- Average weekly sales
- Highest and lowest sales
- Top-performing stores
- Lowest-performing stores
- Store-wise total sales
- Store-wise average sales
- Holiday vs non-holiday sales
- Monthly sales trends
- Fuel price vs weekly sales
- Sales distribution

## 📊 Visualizations

The project includes:

- Store-wise Sales Bar Chart
- Monthly Sales Trend Line Chart
- Holiday vs Non-Holiday Sales Chart
- Weekly Sales Distribution Histogram
- Fuel Price vs Weekly Sales Scatter Plot
- Weekly Sales Box Plot

## 💡 Key Business Insights

- Store performance varies significantly across locations.
- Some stores consistently generate higher sales than others.
- Sales patterns can be analyzed across different months.
- Holiday periods can be compared with regular weeks to understand seasonal behavior.
- External factors such as fuel price, temperature, CPI, and unemployment can be explored for their relationship with sales.
